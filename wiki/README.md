# wiki

Папка для вики-материалов по базе предметов KCD2 (лор, описания, статьи,
справочники для «Богемия RP»).

Сюда можно складывать `.md`, `.json`, `.csv`, изображения — всё попадёт в
репозиторий. Если материалов станет много или они будут тяжёлыми, папку можно
вынести в отдельную ветку/репозиторий.

## Что уже есть рядом

- `../index.html` — сам сайт-база предметов (открывается как есть)
- `../data/reference/items_tagged.json` — 3 784 предмета с русскими названиями,
  категориями и подкатегориями
- `../src/retag_items.py` — правила классификации
- `../README.md` — описание проекта и сборки
