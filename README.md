# База предметов Kingdom Come: Deliverance II — Богемия RP

Статическая база предметов KCD2 на русском языке: оружие, доспехи и одежда, еда,
зелья, травы, книги, кости, материалы и прочее — с иконками, характеристиками
и игровыми ID для консольных команд.

**Сайт:** https://markuzewb.github.io/KCD2BaseItem/

---

## Что внутри

| Показатель | Значение |
|---|---|
| Записей в игре | **4 611** |
| Строк в базе | **2 295** |
| Иконок | 3 313 |
| Категорий | 11 |
| Размер страницы | ~600 КБ (включая данные) |
| Размер спрайтов | 7,7 МБ (21 лист) |

Одинаковые по характеристикам предметы (разные расцветки и геральдика) свёрнуты
в одну строку с пометкой **×N**. В карточке перечислены все игровые ID — итого
доступны все **4 611** записей.

## Возможности

- **Поиск** по русскому и английскому названию, а также по игровому ID.
- **Категории** и **подкатегории** — все видны одновременно, без выпадающих меню.
- **Сортировка** по названию, цене, весу, прочности и количеству вариантов.
- **Два режима просмотра** — карточки и таблица.
- **Карточка предмета**: иконка, характеристики, категория, все ID вариантов,
  готовая команда `wh_cheat_addItem` с копированием в один клик.
- **Экспорт CSV** по текущей выборке (с учётом фильтров и поиска).
- Всё содержимое страницы, кроме спрайтов иконок, встроено в один `index.html`,
  поэтому данные доступны офлайн после первой загрузки.

## Как это собрано

```
data/raw/item.json          выгрузка игровых предметов (5 309 записей)
data/raw/text_ui_dict.json  строки интерфейса (английские названия)
data/raw/icons/             5 250 игровых webp-иконок
src/lexicon_ru.py           русский словарь: ~1 950 существительных, ~460
                            точных названий, ~120 атрибутивных форм, ~130
                            составных названий
src/names_ru.py             имена собственные и их родительный падеж
src/grammar_ru.py           сборка русских названий (согласование, падежи)
src/build_items.py          → data/items.json
src/build_icons.py          → assets/icons/sheet-N.webp + data/icons.json
src/build_site.py           → index.html
```

Пересборка с нуля:

```bash
python3 src/build_items.py     # данные
python3 src/build_icons.py     # спрайты (нужен Pillow)
python3 src/build_site.py      # страница
```

## Иконки

Иконки вырезаны из игровых webp-файлов и упакованы в 21 спрайт-лист по 256
иконок (ячейка 64 px, 16 колонок). Спрайты лежат в `assets/icons/`, координаты —
в `data/icons.json`. Они не встраиваются в `index.html`, потому что base64
раздул бы страницу на ~10 МБ; вместо этого подключаются файлами.

Внешние источники вроде `inara.cz` поддерживаются как альтернатива, но для
работы страницы не нужны.

## О русских названиях

Официальной русской локализации KCD2 в открытом доступе нет, поэтому названия
собраны собственным словарём (`src/lexicon_ru.py` и `src/grammar_ru.py`):
переводятся отдельные слова, а затем собираются с согласованием прилагательных
по роду и числу и постановкой имён в родительный падеж.

Это значит:

- **Терминология может отличаться от того, что вы увидите в игре.**
  Там, где официальный перевод известен, он использован; в остальных случаях
  название построено по правилам русского языка.
- Спорные места вынесены в словарь явными исключениями и правятся в одном файле.
- Английское название показано в карточке предмета — по нему всегда можно
  сопоставить предмет с игрой.

Если вы знаете официальный вариант названия, добавьте строку в
`COMPOUND` (полное название) или `NOUNS`/`ATTR` (отдельное слово) в
`src/lexicon_ru.py` и пересоберите данные.

## Игровые ID и команды

ID предметов — это UUID из игровых данных. Команда выдачи в консоли:

```
wh_cheat_addItem <ID>
```

Скопировать ID можно прямо из карточки предмета. Консоль в KCD2 включается
модом (например, `-devmode` или через Cheat mod), сама игра её не открывает.

## Оговорки

- Проект неофициальный и не связан с Warhorse Studios.
- Данные и иконки принадлежат Warhorse Studios / Deep Silver.
- Категории и подкатегории восстановлены по внутренним именам мешей, слотов
  и иконок, потому что в выгрузке нет прямого поля слота. Возможны единичные
  ошибки классификации.
- Книги, записки и квестовые предметы в базе есть, но их содержимое не
  переведено — только названия.

## Технологии

Чистый HTML, CSS и JavaScript без сборщиков и зависимостей. Один файл
`index.html` с встроенными данными, 21 webp-спрайт, `.nojekyll` для GitHub Pages.
