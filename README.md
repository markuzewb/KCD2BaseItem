# База предметов Kingdom Come: Deliverance II — Богемия RP

Статическая база предметов KCD2 на русском языке с иконками, характеристиками
и игровыми ID для консольных команд.

**Сайт:** https://markuzewb.github.io/KCD2BaseItem/

---

## Что внутри

| Показатель | Значение |
|---|---|
| Предметов | **3 784** |
| Категорий | **13** |
| Подкатегорий | **94** |
| Иконок | 3 778 (внешние ссылки на inara.cz) |
| Размер страницы | 3,1 МБ (данные встроены) |

`index.html` — **точная копия** эталонного файла `KCD2_Items.html`
(лежит в `data/reference/`): тот же CSS, разметка, JavaScript и те же иконки.
Сборщик ничего не меняет, кроме удаления постороннего Cloudflare-скрипта,
который сайт-источник вставил при скачивании.

Иконки подгружаются по внешним ссылкам на `inara.cz` — так же, как в
исходном файле. Для работы страницы нужен интернет.

## Возможности

- **13 категорий**: алхимия и травы, боеприпасы, доспехи и одежда, оружие
  ближнего и дальнего боя, еда и напитки, книги и документы, кости и бляхи,
  материалы, трофеи и ценности, ключи, инструменты и ремонт, прочее.
- **94 подкатегории**, разложенные по внутреннему имени меша, слоту
  «Одежда (база)» и локализованной подписи. У брони 31 подкатегория
  (шлемы, шапки, чепцы, венки, койфы, капюшоны, кирасы, бригантины,
  кольчуги, гамбезоны, ваффенроки, котарди, туники, куртки, кафтаны, рясы,
  защита ног, штаны, ботинки/сапоги/туфли, перчатки, рукавицы, наручи,
  бармицы, шпоры, очки, украшения, пояса, сумки, упряжь), у книг 8,
  у еды 11, у материалов 9, у трофеев 6.
- **Технические «свалки» убраны**: «Псевдонимы предметов», «Разные предметы»,
  дубли «Ключи» и «Тестовые» разложены по смыслу.
- **Бейдж «Ж»** у женских вещей — вместо отдельной категории.
- **Поиск** по русскому и английскому названию, внутреннему Name и ID.
- **Сортировка** по названию, цене и весу; **фильтры** «только с ценой»,
  «только с весом», «только с иконкой».
- **5 604 предмета** — полная выгрузка игровых файлов, включая конскую
  упряжь и объекты мира, 16 категорий и 99 подкатегорий.
- **Таблица и карточки**, пагинация по 25/50/100.
- **Карточка предмета**: все характеристики из игры (57 220 значений),
  разбитые по группам — бой, защита, требования, действие, общее;
  каждая подпись и единица измерения по-русски. Поиск идёт и по
  характеристикам, есть фильтр «только с характеристиками».
- **Экспорт CSV** по текущей выборке.
- Горячая клавиша `/` — фокус в поиск, `Esc` — закрыть карточку.

## Анимации

Сверху сайта переключатель разделов: **Предметы** / **Анимации**. Второй
раздел — каталог 9 006 клипов KCD2 из `wiki/KCD2_animations_full_reference_9006 (1).xlsx`.

- 37 категорий (Бой / турнир, Диалоги / жесты, Сюжетные сцены, Передвижение,
  Кузнец, Пекарь…) и 178 подкатегорий внутри крупных групп.
- Русское название строится из имени клипа: `combat_clinch1_sz1_az2_
  attacksync_backoff_blunt_master` → **Захват 1**, а технические коды
  (сторона, зона удара, синхронизация) уходят в «детали исполнения».
- Под названием мелким шрифтом — смысл из файла-справочника.
- **Имя анимации копируется одной кнопкой** — и в строке таблицы, и в карточке.
- Поиск идёт по русскому названию, имени клипа, описанию, фазе,
  семейству и Fragment.

Сборка:

```bash
python3 src/build_animations.py   # xlsx → data/reference/anim_*.json
python3 src/build_anims_site.py   # → index.html
```

Словарь перевода имён — `src/anim_words.py`: 327 технических кодов
и 1 283 смысловых слова плюс винительный падеж и глаголы, чтобы названия
читались как «лесоруб собирает ветку», а не «лесоруб, сбор, ветка».

## Как это собрано

```
data/reference/KCD2_Items.html   эталонный файл — источник вёрстки index.html
data/reference/items_full.json   5 604 предмета, все характеристики (6 МБ)
data/reference/cats_full.json    16 категорий, subs_full.json — 99 подкатегорий
src/item_fields.py               русские подписи, единицы и расшифровки полей
src/build_catalog.py             архив wiki/ → *_full.json
src/build_full.py                → index.html (эталон + полная база)
data/reference/items.json        3 784 предмета (прежняя база, для истории)
data/reference/items_tagged.json прежняя разметка (13 категорий)
src/retag_items.py               → *_tagged.json (прежняя таксономия)
src/build_site.py                → index.html по прежней базе (устарел)
assets/icons/sheet-N.webp        21 спрайт-лист (не используется на сайте)
data/icons.json                  координаты иконок (не используется на сайте)
src/build_icons.py               → assets/icons/ + data/icons.json
src/build_items.py               → собственный датасет (см. ниже)
src/lexicon_ru.py, src/grammar_ru.py, src/names_ru.py
                                 словарь и грамматика русского
```

Пересборка страницы:

```bash
python3 src/build_catalog.py   # архив wiki/ → data/reference/*_full.json
python3 src/build_full.py      # собрать index.html
```

`build_catalog.py` читает `wiki/KCD2_ITEMS_RESULTS.zip`, раскладывает все
5 604 предмета по категориям (эвристики по типу XML, имени модели и полю
`Class`), переводит характеристики через `src/item_fields.py`.
`build_full.py` берёт эталонную вёрстку и подставляет в неё данные,
вывод характеристик по группам, поиск по ним и метку «Ж».

`build_site.py` — прежняя сборка по 3 784 предметам; она осталась
для истории и запускать её не нужно: она перезапишет полную базу.

## Две базы в репозитории

| | `data/reference/` | `data/items.json` |
|---|---|---|
| Предметов | 3 784 | 4 611 |
| Источник | эталонный файл | выгрузка `item.json` |
| Русские названия | официальная локализация | собственный словарь |
| На сайте | **да** | нет |

`src/build_items.py` и словарь (`lexicon_ru.py`, `grammar_ru.py`) оставлены
для истории: это альтернативная сборка на 4 611 записей с переведёнными
вручную названиями. На сайт она сейчас не выводится, но скрипты рабочие —
`data/items.json` пересобирается командой `python3 src/build_items.py`.

## О русских названиях

В основной базе (`data/reference/`) названия взяты из официальной
локализации игры — в поле `note` указано, откуда взято название: «Официальная
локализация», «Официальная локализация (ручное сопоставление)», «Перевод
(базовый ингредиент)» или «Тестовый предмет».

## Оговорки

- Проект неофициальный и не связан с Warhorse Studios.
- Данные и иконки принадлежат Warhorse Studios / Deep Silver.
- 11 предметов помечены как тестовые — они есть в файлах игры, но недоступны
  в обычном прохождении.
- Иконки загружаются с `inara.cz`. Если сайт недоступен или ссылка устарела,
  вместо картинки показывается эмодзи категории.
- Папка `assets/icons/` с локальными спрайтами осталась в репозитории от
  предыдущей версии, но текущая страница её не использует.
