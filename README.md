# База предметов Kingdom Come: Deliverance II — Богемия RP

Статическая база предметов KCD2 на русском языке с иконками, характеристиками
и игровыми ID для консольных команд.

**Сайт:** https://markuzewb.github.io/KCD2BaseItem/

---

## Что внутри

| Показатель | Значение |
|---|---|
| Предметов | **3 784** |
| Категорий | **19** |
| Подкатегорий | **~60** |
| Иконок | 3 778 (внешние ссылки на inara.cz) |
| Размер страницы | 3,1 МБ (данные встроены) |

`index.html` — **точная копия** эталонного файла `KCD2_Items.html`
(лежит в `data/reference/`): тот же CSS, разметка, JavaScript и те же иконки.
Сборщик ничего не меняет, кроме удаления постороннего Cloudflare-скрипта,
который сайт-источник вставил при скачивании.

Иконки подгружаются по внешним ссылкам на `inara.cz` — так же, как в
исходном файле. Для работы страницы нужен интернет.

## Возможности

- **19 категорий** по игровому типу: оружие ближнего и дальнего боя, шлемы,
  капюшоны, броня и одежда, боеприпасы, еда, травы, книги, кости, бляхи для
  костей, материалы, зелья, духи и наборы для ремонта, кошельки и пояса.
- **Подкатегории** с ручной разметкой: у брони 12 (женская одежда, жакеты и
  варффероки, головные уборы, штаны, рубашки, обувь, рукава, бригантины,
  гамбезоны, койфы, украшения), у книг 6, у еды 5, у капюшонов 11.
- **Поиск** по русскому и английскому названию, внутреннему Name и ID.
- **Сортировка** по названию, цене и весу; **фильтры** «только с ценой»,
  «только с весом», «только с иконкой».
- **Таблица и карточки**, пагинация по 25/50/100.
- **Карточка предмета**: все характеристики из игры, ID, кнопки копирования.
- **Экспорт CSV** по текущей выборке.
- Горячая клавиша `/` — фокус в поиск, `Esc` — закрыть карточку.

## Как это собрано

```
data/reference/KCD2_Items.html   эталонный файл — источник index.html
data/reference/items.json        3 784 предмета (для справки)
data/reference/cats.json         19 категорий (для справки)
data/reference/subs.json         подкатегории (для справки)
src/build_site.py                → index.html (копия эталона)
assets/icons/sheet-N.webp        21 спрайт-лист (не используется на сайте)
data/icons.json                  координаты иконок (не используется на сайте)
src/build_icons.py               → assets/icons/ + data/icons.json
src/build_items.py               → собственный датасет (см. ниже)
src/lexicon_ru.py, src/grammar_ru.py, src/names_ru.py
                                 словарь и грамматика русского
```

Пересборка страницы:

```bash
python3 src/build_site.py
```

Скрипт копирует эталон в `index.html` один в один.

## Две базы в репозитории

| | `data/reference/` | `data/items.json` |
|---|---|---|
| Предметов | 3 784 | 4 611 |
| Источник | эталонный файл | выгрузка `item.json` |
| Русские названия | официальная локализация | собственный словарь |
| На сайте | **да** | нет |

`src/build_items.py` и словарь (`lexicon_ru.py`, `grammar_ru.py`) оставлены
для истории: это альтернативная сборка на 4 611 записей с переведёнными
вручную названиями. На сайт она сейчас не выводится, но скрипты рабочие —
`data/items.json` пересобирается командой `python3 src/build_items.py`.

## О русских названиях

В основной базе (`data/reference/`) названия взяты из официальной
локализации игры — в поле `note` указано, откуда взято название: «Официальная
локализация», «Официальная локализация (ручное сопоставление)», «Перевод
(базовый ингредиент)» или «Тестовый предмет».

## Оговорки

- Проект неофициальный и не связан с Warhorse Studios.
- Данные и иконки принадлежат Warhorse Studios / Deep Silver.
- 11 предметов помечены как тестовые — они есть в файлах игры, но недоступны
  в обычном прохождении.
- Иконки загружаются с `inara.cz`. Если сайт недоступен или ссылка устарела,
  вместо картинки показывается эмодзи категории.
- Папка `assets/icons/` с локальными спрайтами осталась в репозитории от
  предыдущей версии, но текущая страница её не использует.

## Технологии

Чистый HTML, CSS и JavaScript без сборщиков и зависимостей. Один файл
`index.html`, `.nojekyll` для GitHub Pages.
